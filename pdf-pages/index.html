选页、删页、调顺序、多个 PDF 合成一个。文件不上传。

① 选 PDF（可以选多个，会按顺序接在一起）

    ② 点小图选页（蓝框 ✓ 的会保留）

    只要第页

    页码按下面排的顺序数。← → 调顺序，↻ 把这一页顺时针转 90°，✕ 把这一页从列表里拿掉。

    保存 PDF

    手机上保存后一般在“下载”或“文件”里能找到。原文件不会被改动。

    关于本页

    选一个或几个 PDF，看着每页的小图点选要哪几页，还能调顺序、把某一页转个方向，最后保存成一个新 PDF。文件只在你自己的浏览器里处理，不上传、不保存。

    常见问题

    PDF 只要其中几页，怎么单独保存出来？
    选 PDF 后点“全不选”，再点要的那几页（或在“只要第__页”里填 1-3,5 这样的页码），点“保存选中的页为新 PDF”。

    怎么删掉 PDF 里的某一页？
    把那一页点成灰色（不选），或点它下面的 ✕，再保存。保存的是新文件，原文件不变。

    几个 PDF 怎么合成一个？
    第①步一次选几个（或分几次添加），所有页会按顺序排在一起，用 ← → 调好顺序再保存。页面大小不一样的 PDF 合在一起后，每页保持各自原来的大小。

    PDF 里有一页是横的、倒的，怎么转过来？
    点那一页下面的 ↻，每点一次顺时针转 90°，小图会跟着转，转对了再保存。

    保存后文字还能复制吗？清晰度会变吗？
    能复制，不变。这里是把原来的页面原样搬到新文件里，不重新压缩。要把文件变小，用PDF 太大传不上去。

    提示“这个文件有密码”？
    加了密码或权限保护的 PDF 本页处理不了。

    文件会被传到网上吗？
    不会。全部在你的设备上完成。页数很多时小图会边看边加载；文件特别大时手机可能内存不够，换电脑更稳。
