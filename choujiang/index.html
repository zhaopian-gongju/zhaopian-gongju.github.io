三步用法：

  1. 贴名单，设好每个奖项的名称和人数。
  2. 点“进入大屏开始抽奖”，接投影或全屏显示。
  3. 按空格开始、停止，一个奖项抽满后点“下一个奖项”，最后复制或导出结果。

常见问题

怎么操作？
贴名单 → 设奖项 → “进入大屏开始抽奖” → 空格键（或点“开始”）名字开始滚动 → 再按空格停下，显示中奖人。一个奖项抽满后点“下一个奖项”。按 Esc 或点“退出大屏”回到设置页。

一次抽好几个人？
大屏下方“本次抽 N 人”改成想要的数，一次停下就出 N 个名字，比如三等奖 10 个一次抽完。

随机公平吗？
停下那一刻才从还没中奖的人里随机挑，用的是浏览器自带的密码学随机数（crypto.getRandomValues），每个人机会相同。滚动时屏幕上闪过的名字只是动画，不影响结果。

中过的人还能再中吗？
默认不能。想让中过的人还能参加后面的奖项，取消勾选“中过奖的人不再参与后面的抽奖”（同一个奖项里还是不会重复）。

抽错了 / 中奖人不在场？
大屏上点“撤销上一次”，刚才那一批作废，可以重抽。

名单里有同名的人？
完全一样的行只算一次。同名不同人请在逗号后面写上部门，例如“张伟,技术部”和“张伟,财务部”。

不小心刷新了 / 关了页面？
名单、奖项和结果都存在这台电脑的浏览器里，重新打开本页还在。用浏览器的“无痕 / 隐私模式”时关掉就没了。
